docker-watcher-test 작업.

커밋 메시지는 둘 다 "update readme"인데 실제로는 README만 바꾼 게 아니었다. 첫 커밋에서 README.md를 새로 만들면서 410줄을 썼고, 같이 `config/watcher.yml`에 34줄, `app/main.py`에 29줄 추가하고 11줄 지웠다. `app/config.py`도 한 줄 바꿨다.

## watcher 설정

`watcher.yml`이 1줄 빼고 34줄 늘어난 걸 보면 설정 항목을 꽤 늘린 것 같다. `main.py` 변경도 그 설정을 읽는 쪽에 맞춘 거고, `config.py` 한 줄은 아마 설정 파일 경로나 기본값 정도. 정확히 뭘 늘렸는지는 커밋만 봐서는 안 보여서 다음에 따로 정리해야겠다.

## README

410줄이면 사실상 문서를 처음부터 쓴 거다. 두 번째 커밋은 README 2줄 고친 게 전부라 오타 정도였던 듯.

커밋 메시지를 "update readme" 하나로 퉁쳤더니 나중에 보니까 뭘 했는지 알기 어렵다. 설정 변경이랑 문서는 커밋을 나눴어야 했다.

남은 것: watcher.yml에 추가한 항목 설명을 README에 맞춰 놨는지 확인.
