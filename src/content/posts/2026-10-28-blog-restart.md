2022년에 Hugo 로 만들어 두고 글 하나 없이 쉬던 블로그를 **Astro** 로 새로 지었습니다.

## 바꾼 것

- **Astro + GitHub Pages**: 글은 마크다운으로 쓰고, `main` 에 올리면 GitHub Actions 가 빌드해서 바로 배포합니다.
- **기술별 메뉴**: 백엔드, 프론트엔드, 인프라 같은 카테고리를 글마다 하나씩 붙이고, 위쪽 메뉴에서 카테고리별로 모아 볼 수 있습니다.
- **다크 모드, RSS, 태그**: 기본으로 넣었습니다.

## 매일 기록

하루에 한 번, 전날 공개 저장소에 올린 커밋을 모아 개발 기록 초안을 만드는 작업이 돌아갑니다.

1. 커밋 메시지와 바뀐 파일 목록만 모읍니다. 코드 내용은 보내지 않습니다.
2. 이메일, IP, 토큰, 접속 문자열 같은 민감한 값을 지웁니다.
3. 초안을 글로 다듬고, 결과를 한 번 더 검사합니다.
4. 바로 게시하지 않고 **PR 로 올립니다.** 읽고 고친 뒤 머지해야 게시됩니다.

앞으로 여기에 꾸준히 쌓아 가겠습니다.
