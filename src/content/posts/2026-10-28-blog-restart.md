2022년에 Hugo + PaperMod 로 블로그를 만들어 놓고 "Init" 글 하나 올린 뒤로 4년을 그냥 뒀다. 글이 하나도 없으니 옮길 것도 없어서, 이참에 Astro 로 새로 만들었다.

## 왜 Astro

Hugo 도 빠르고 괜찮았는데 템플릿 문법(Go template)을 만질 때마다 다시 찾아봐야 했다. Astro 는 컴포넌트가 그냥 HTML + JS 라 손대기 편하다. Content Collections 로 글 frontmatter 를 스키마로 검사할 수 있는 것도 좋았다. 카테고리에 오타를 내면 빌드가 실패한다.

배포는 예전처럼 `gh-pages` 브랜치에 결과물을 올리지 않고 GitHub Actions 에서 빌드해서 Pages 로 바로 보낸다. `main` 에 push 하면 1분 안에 반영된다.

## 메뉴는 기술별로

글마다 카테고리를 하나씩 붙이고 상단 메뉴를 백엔드, 프론트엔드, 인프라 이런 식으로 나눴다. 하는 일이 백엔드 위주지만 인프라나 DB 쪽 작업도 꽤 있어서 나중에 찾아보기 편하게 하려고.

## 매일 기록 자동화

전날 공개 저장소에 올린 커밋을 모아서 일지 초안을 PR 로 올리는 Actions 를 붙였다. 커밋 메시지랑 바뀐 파일 목록만 쓰고 코드는 안 보낸다. 토큰이나 이메일, 내부 주소 같은 건 초안 만들기 전에 정규식으로 한 번, 만든 뒤에 한 번 더 지운다.

바로 게시되진 않고 PR 을 직접 읽고 고쳐서 머지해야 올라간다. 커밋 메시지를 "update readme" 수준으로 쓰면 초안도 그만큼 빈약해져서, 커밋 메시지부터 좀 성의 있게 써야 할 것 같다.
